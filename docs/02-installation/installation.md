# Installation

This guide explains how to install **The Sign Pack Tools** on a workstation running Adobe Illustrator.

Before starting the installation, make sure the system meets the requirements described in [Requirements](requirements.md).

## Before Installing

Before installing The Sign Pack Tools:

1. Close **Adobe Illustrator**.
2. Make sure you have access to the latest version of the The Sign Pack Tools package provided by the company.
3. Confirm that your computer meets the required Illustrator and CEP versions.
4. Make sure you have permission to install or modify the required files and folders on your computer.

## Installation Overview

The Sign Pack Tools is installed as an **Adobe CEP extension**.

The installation consists of placing the extension files in the appropriate Adobe CEP extension directory and configuring the system so that Illustrator can load CEP extensions.

The general installation process is:

1. Obtain the The Sign Pack Tools extension package.
2. Install or copy the extension files to the appropriate CEP extensions directory.
3. Configure CEP debugging/signing requirements if necessary.
4. Open Adobe Illustrator.
5. Verify that The Sign Pack Tools appears in Illustrator.
6. Launch the extension and confirm that it loads correctly.

## Windows Installation

On Windows, the extension files are installed in the Adobe CEP extensions directory associated with the current user.

The exact installation path depends on the Adobe CEP configuration used by the workstation.

After the extension has been installed:

1. Launch Adobe Illustrator.
2. Open the **Window** menu.
3. Locate **The Sign Pack Tools** in the available extensions.
4. Open the extension.
5. Confirm that the main interface loads correctly.

If the extension does not appear or does not load, see the [Troubleshooting](../10-troubleshooting/cep-problems.md) section.

## macOS Installation

On macOS, the extension files are installed in the Adobe CEP extensions directory associated with the current user.

The installation procedure is similar to Windows, although the file system location and some system configuration steps are different.

After the extension has been installed:

1. Launch Adobe Illustrator.
2. Open the **Window** menu.
3. Locate **The Sign Pack Tools** in the available extensions.
4. Open the extension.
5. Confirm that the main interface loads correctly.

If the extension does not appear or does not load, see the [Troubleshooting](../10-troubleshooting/cep-problems.md) section.

## First Launch

After opening The Sign Pack Tools for the first time, verify that:

- The extension window opens correctly.
- The main menu is displayed.
- The available tool categories are visible.
- The tools can be selected.
- The extension can communicate with Adobe Illustrator correctly.

The first launch is also a good opportunity to verify that the **Library** and other shared systems are functioning correctly.

## Installation Verification

A successful installation should result in the **The Sign Pack Tools** panel being available inside Adobe Illustrator.

The main interface should provide access to the available categories:

- **File Templates**
- **Tools**
- **Design Tools**
- **Production**

If these categories are displayed and the extension responds correctly when a tool is selected, the installation is generally complete.

## If the Installation Fails

If The Sign Pack Tools does not appear in Illustrator, does not open, or a tool fails to execute:

1. Close Adobe Illustrator.
2. Verify that the extension files were installed in the correct location.
3. Verify that the required CEP configuration is enabled.
4. Reopen Adobe Illustrator.
5. Try launching The Sign Pack Tools again.

If the problem persists, consult the [Troubleshooting](../10-troubleshooting/cep-problems.md) documentation.

For development or maintenance issues, refer to the **Development** section of this documentation.
