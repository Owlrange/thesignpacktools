# Requirements

Before installing **The Sign Pack Tools**, make sure the following requirements are met.

## Adobe Illustrator

The Sign Pack Tools is designed to run on:

- **Adobe Illustrator 2026**
- **Version 30.6 or later**

The system was developed and tested with **Illustrator 30.6** and **Illustrator 30.7**.

## CEP Version

The Sign Pack Tools uses **Adobe CEP (Common Extensibility Platform) version 12**.

CEP 12 is required for the extension to load and communicate with Adobe Illustrator correctly.

## Operating System

The Sign Pack Tools supports:

- **Windows**
- **macOS**

The core functionality of the extension is designed to work across both operating systems.

Some installation procedures or system-level configuration may differ between Windows and macOS.

## Internet Connection

An internet connection is not required for the core tools to operate.

However, some features may provide links to external resources, such as content available through **TSP University**. Accessing these external resources requires an internet connection.

## Requirements Summary

| Requirement | Supported |
|---|---|
| Adobe Illustrator | 2026 — Version 30.6 or later |
| Tested Illustrator Versions | 30.6 and 30.7 |
| CEP | Version 12 |
| Operating System | Windows / macOS |
| Internet | Required only for external resources |
