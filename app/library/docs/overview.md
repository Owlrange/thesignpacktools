# Getting Started

Welcome to the documentation for **The Sign Pack Tools**.

This section provides an introduction to the system, its purpose, and the main concepts you should understand before working with the tools.

Whether you are using The Sign Pack Tools as a production artist or working on the development and maintenance of the extension, the Getting Started section provides the foundation for understanding how the system is organized.
