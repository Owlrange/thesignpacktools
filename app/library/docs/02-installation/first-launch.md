# First Launch

After installing **The Sign Pack Tools**, the first launch should be used to verify that the extension is installed correctly and can communicate with Adobe Illustrator.

## Opening The Sign Pack Tools

1. Open **Adobe Illustrator**.
2. Open the **Window** menu.
3. Locate **The Sign Pack Tools** in the available extensions.
4. Open the extension.

The main The Sign Pack Tools interface should appear inside Illustrator.

## Verify the Interface

After opening the extension, verify that the main categories are displayed:

- **File Templates**
- **Tools**
- **Design Tools**
- **Production**

If these categories are visible, the CEP extension has loaded successfully.

## Test a Tool

The next step is to verify that The Sign Pack Tools can communicate with Adobe Illustrator correctly.

Create or open an Illustrator document and test a simple tool.

For example, a tool from the **Tools** category can be used to verify basic communication between the extension and Illustrator.

The expected result is that:

1. The tool can be selected from the interface.
2. The operation starts without an extension error.
3. The corresponding action is performed in the Illustrator document.
4. The extension remains responsive after the operation.

## Verify File Templates

Open the **File Templates** category and verify that the available templates are displayed.

The current templates include:

- **Standard Template**
- **ADA Template**
- **Vehicle Template**

Select a template only when appropriate for testing, as templates may create or modify the active Illustrator document.

## Verify Production Tools

Open the **Production** category and confirm that the available production tools are displayed.

The current category includes tools such as:

- **Prod Preparation**
- **Create Outline**
- **Create Cut Contour**
- **Create Bounding Box**
- **Make White Ink**
- **Grommets / Hole Marks**
- **Pre-flighting**

Not every production tool needs to be executed during the initial installation test.

## Verify Design Tools

Open the **Design Tools** category and confirm that the available tools are displayed.

The current category includes:

- **Check Named Colors**
- **Check Image Quality**
- **SQFT Callout**
- **SQFT Calculator**
- **Scale Factor**

Again, simply confirming that the tools are available is sufficient for the initial installation check.

## Successful Installation

The installation can be considered successful when:

- The extension appears in Adobe Illustrator.
- The main interface opens correctly.
- The four main categories are displayed.
- Tools can be selected.
- At least one tool executes successfully.
- The extension remains responsive after execution.

At this point, The Sign Pack Tools is ready for normal use.

## If Something Goes Wrong

If the extension does not appear, does not open, or tools cannot be executed, do not modify project files manually unless you are responsible for maintaining the extension.

Start with the [Troubleshooting](../10-troubleshooting/installation-problems.md) section.

For development-related problems, refer to the [Development](../07-development/architecture.md) documentation.
